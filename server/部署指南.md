# 远近通记 - 微信提醒部署指南

## 第一步：申请微信模板消息

1. 登录微信公众号后台 https://mp.weixin.qq.com
2. 左侧菜单 → **功能** → **模板消息** → 从模板库添加
3. 搜索"日程提醒"或"待办提醒"类模板，申请使用
4. 审批通过后，记录 **模板ID**（一串字母数字，如 `abc123def456...`）

> 模板字段必须包含：`first`、`keyword1`、`keyword2`、`keyword3`、`remark`
> 如果模板字段名不同，可在 `server/app.py` 的 `_do_send_reminders()` 中修改 `data` 字段名

## 第二步：获取你的 OpenID

1. 用你自己的微信关注你自己的公众号
2. 在公众号后台 → 用户管理 → 找到你自己的用户
3. 记下你的 **OpenID**（以 `o` 开头的字符串）

## 第三步：获取 AppID 和 AppSecret

1. 公众号后台 → 开发 → 基本配置
2. 记下 **AppID** 和 **AppSecret**（AppSecret 需扫码重置后查看）

## 第四步：部署后端服务

### 方式 A：CloudStudio 沙箱部署（免费）

1. 将 `server/` 目录上传到 CloudStudio
2. 配置环境变量（AppID、AppSecret、OpenID、TemplateID、API_KEY）
3. 启动命令：`pip install -r requirements.txt && gunicorn app:app -b 0.0.0.0:5000`
4. 记下 CloudStudio 给你的 URL

### 方式 B：自己的服务器

```bash
cd server
pip install -r requirements.txt
export WECHAT_APPID=你的AppID
export WECHAT_APPSECRET=你的AppSecret
export WECHAT_OPENID=你的OpenID
export TEMPLATE_ID=你的模板ID
export API_KEY=你的随机APIKey
gunicorn app:app -b 0.0.0.0:5000 --daemon
```

### 备用调度方案

如果 CloudStudio 沙箱休眠导致 APScheduler 不工作，可使用外部 cron 服务：

1. 注册 https://cron-job.org （免费）
2. 创建 cron job，每天 08:00 北京时间
3. URL：`https://你的服务器地址/send-reminders?key=你的API_KEY`
4. 方法：POST

这样即使内置调度器不工作，外部 cron 也会每天早上8点触发提醒。

## 第五步：前端配置同步

1. 打开 https://yushupyq.github.io/yuanjin-tongji/
2. 点击 📡 按钮
3. 填入后端服务器地址（如 `https://xxx.cloudstudio.work/sync`）和 API Key
4. 点击"保存并同步"

每天同步一次，或者手动同步即可。
